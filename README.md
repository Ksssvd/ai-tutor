# ai-tutor

> 把 AI 变成私人老师：先摸清你的水平，再从你的目标倒推学习路线；一次只问一道题，严格打分，只讲你没掌握的部分；答错的题隔几天再考；定期对照目标看还差多少；想转行时从真实岗位 JD 倒推，用模拟面试过关；进度记在文件里，下次说"继续"就能接着学。

## 解决什么问题

直接让 AI 教你，通常是这样的：它讲一大段，你看完觉得懂了，一开口就卡住；下次再聊，它已经忘了你学到哪、哪里总出错。

问题不在 AI 讲得不好，而在于缺了几个学习过程中最关键的环节：

- **没对准目标**：学 Python 做数据分析和学 Python 做网站，要学的东西差别很大；
- **只输入不输出**：看懂别人讲，不等于自己会；
- **没有复习**：学完不复习，一周后大部分都会忘掉；
- **没有记忆**：每次对话都从零开始。

ai-tutor 是一份 Skill（一个 `SKILL.md` 说明书文件），它把这些环节写成 Agent 必须遵守的教学流程。

## 它怎么教

**第一次：建档**
1. 一次问清：学完要能做成什么、期限、每周时间、现有基础、限制条件；
2. 出 3–5 道摸底题，测出真实水平，不靠你自己评估；
3. 从目标倒推出 3–5 级路线，每级写清：要会什么、动手任务、过关标准、常见错误；
4. 期限明显不够时直说，给出现实的范围；
5. 写好进度文件（笔记位置可以自己指定，比如 Obsidian 笔记库）。

**每次上课**
1. 先考到期的复习题；
2. 学一小块新内容：讲最少必要的部分（新手先用生活类比，并说明类比在哪里不成立）→ 给完整例子 → 你自己做 → 批改 → 补缺口；
3. 检验：**问答**（一次一题，先标"有把握 / 不确定"）、**讲回来**（用你自己的话讲给外行听），或**找边界**（这个结论在什么前提下成立、什么时候失效、有没有反例）；
4. 收尾：生成一页速查卡并按日期保存，答错和"不确定"的题都放进复习队列。

**阶段评估**：每 5 课、每次升级前，或你问"我离目标还差多少"时，对照目标给每项能力打 0–5 分，写清依据，指出最该补的 1–2 项。

**复习间隔**：答错的题 1 天后再考，之后每答对一次，间隔依次拉长到 3 → 7 → 14 → 30 天；再答错就回到 1 天。

**目标是找工作或转行时**，会额外读取 `references/job-goal.md`：
1. 用 10–30 条真实 JD 定目标。你贴最好；让 AI 去找时，它会先把来源列给你确认，拿不到就直说，不编；
2. 提炼岗位要求表（哪些是必需、出现在几条 JD 里、要到什么程度），摸底题从必需要求里出；
3. 路线里的动手任务尽量做成作品集；
4. 过关检验是**模拟面试**：一次一题、会追问，面试中不讲解，结束后逐题按正确性、逻辑、专业程度、表达打分复盘。

**几条硬规则**：先答后讲；一次一题；按 0–3 分严格打分，不客套地夸；只补缺口；推荐书、课程、链接前必须核实确实存在；遇到健康、医疗、法律、财务类问题，涉及伤病、用药等情况时，先建议你找专业人士确认。

## 举个例子：学健身增肌

> **你**：我想学健身，目标是自己排增肌计划、自己算每天该吃多少。
>
> **AI**：先问你 5 个问题……（目标、时间、基础、器械、身体情况）
>
> **AI**：摸底题 3/4：按现在的吃法和练法，连续一个月体重没变，说明什么？先标"有把握"还是"不确定"。
>
> **你**：有把握，说明热量亏空了，要多吃蛋白质。
>
> **AI**：1/3 分。体重稳定，说明你吃在维持线上，不是亏空；该加的是总热量，主要加碳水，不是蛋白质……这题"有把握却答错"，已放进复习队列，明天再考。

## 安装

### Claude Code、Codex 等本地 Agent

```bash
git clone https://github.com/Ksssvd/ai-tutor.git ~/ai-tutor
```

```bash
~/ai-tutor/install.sh
```

脚本会把 skill 软链接到 `~/.claude/skills`（Claude Code 读这里）和 `~/.agents/skills`（Codex 等读这里）。只想装给 Claude Code，就运行 `~/ai-tutor/install.sh claude`。

其他支持 `SKILL.md` 格式的 Agent：把 `skill/ai-tutor` 整个文件夹复制到该 Agent 的 skills 目录即可。

## 使用

装好后，在 Agent 里直接说：

| 你说 | 它做什么 |
|---|---|
| 我想学 X / 教我 X | 第一次：建档、摸底、定路线 |
| 继续 / 今天学什么 | 读进度，先复习，再上新课 |
| 考我 | 一次一题地问答检验 |
| 我讲给你听 | 你讲，它找漏洞，你再重讲 |
| 找边界 | 追问结论的前提、失效场景和反例 |
| 速查表 | 生成本次内容的一页卡 |
| 我离目标还差多少 | 阶段评估 |
| 我想转行做 X | 从 JD 倒推的求职学习路线 |
| 模拟面试 | 扮演面试官，面完逐题复盘 |
| 调整路线 | 修改目标或路线 |
| 推荐资源 | 推荐最多 5 个**核实过**的资源 |

进度保存在当前工作目录下的 `学习/<主题>/进度.md`，只存在你自己的电脑上。Agent 不能写文件时，会在课末把进度内容发给你，你自己保存，下次贴回去即可。

## 局限

- Skill 本身不能定时提醒你复习。你说"提醒我复习"时，如果 Agent 支持定时任务，它会帮你设；不支持就要你自己回来说"继续"；
- 求职用的 JD 数据取决于能拿到什么：招聘平台大多要登录，最可靠的是你自己贴；
- 它的讲解质量取决于你用的模型。冷门领域请留意它标出的"不确定"；
- 它不能替代医生、律师等专业人士的意见。
