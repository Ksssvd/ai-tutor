# 回归测试场景

改完 Skill 后逐条跑。测试学员都是编的，主题统一用"学会用 Excel 做店铺月度销售报表"，求职场景用"转行做数据分析师"。

## 怎么跑

每个场景用一个新的空文件夹（下文写作 `<场景文件夹>`），用命令行 Agent 的非交互模式跑，第一轮新开会话，之后每轮接着上一轮的会话。下面是用 Codex 命令行的写法（需要联网，每条命令给足 500 秒；一条一条顺序跑，因为续轮接的是"最近一次会话"）：

```bash
# 第一轮
cd <场景文件夹> && codex exec --skip-git-repo-check -s workspace-write "<学员的话>" < /dev/null 2>&1 | grep -v "rmcp::transport" > turn1.log
# 续轮（续轮不继承沙箱设置，必须再写一次）
cd <场景文件夹> && codex exec resume --last --skip-git-repo-check -c sandbox_mode=workspace-write "<学员的话>" < /dev/null 2>&1 | grep -v "rmcp::transport" > turn2.log
```

- 命令里的 `< /dev/null` 不能省：后台运行时没有它，Agent 会一直等输入、卡住不动。
- AI 的最终回复在日志里最后一个单独成行的 `codex` 之后。
- 日志里连接 chatgpt.com 的报错可以忽略；Agent 因全局规则在文件夹里多建 SPEC.md / STATE.md 也忽略。
- 场景里的日期按"今天 = 2026-11-12"设计；换日期跑时，手工进度文件里的日期要一起平移。
- 没通过时，先把旧日志改名保留，再改措辞重跑。

## T1 新用户首条回复

- 输入：`我想学会用 Excel 做店铺的月度销售报表，带我学`
- 怎么跑：新文件夹，第一轮。
- 通过标准：回复只有建档问题，分了"必答"和"可选"；没有任何考题，也没有讲课。

## T2 答错先重试（接 T1）

- 输入：
  - 第二轮：回答建档问题。编一个学员：会基本输入和求和，每周 3 小时，其余用默认。
  - 第三轮：对第一道摸底题给一个"方向对但不完整"的回答。
- 通过标准：第三轮的回复指出方向、给一个提示、请学员再试一次，不含完整答案；每条回复最多一道考题。

## T3 中途存档（接 T2）

- 输入：第四轮，再答一次（补全答案）。
- 通过标准：AI 给出完整批改；此时 `学习/` 下已有进度文件，里面有这道题的结果。

## T4 首次会话收尾（接 T3）

- 输入：`今天先到这`
- 通过标准：回复里有一条当天能用的要点（结合学员自己的情境）、最多一件可选小事、下次回来的日期；进度文件已更新，并有"当前待答题"或等价记录。

## T5 复习考变式

- 准备：新文件夹，按 `skill/ai-tutor/references/progress-template.md` 手工建 `学习/Excel月度销售报表/进度.md`：当前级别 1，上次上课 2026-11-11；复习队列 1 题今天（2026-11-12）到期，知识点、正确要点、上次问法写具体，当前间隔 1 天。
- 输入：第一轮 `继续`；拿到复习题后，第二轮给出正确回答。
- 通过标准：复习题的题型和"上次问法"不同（反过来问、找错、解释原因或换情境；只改数字、名称或位置不算通过），但考的是同一个知识点；用户没说时间时，时间是在这条回复里顺带问的，没有单独占一个来回；答对后进度文件里这题的间隔变成 3 天、下次复习日期是 2026-11-15，"上次问法"已更新成这次的问法。

## T6 久别归来

- 准备：新文件夹，手工建进度文件：上次上课 2026-10-14；复习队列 8 题，全部已过期，其中 2 题在"上次结果"里标了"有把握却答错"。
- 输入：第一轮 `继续`；第二轮随便答一题。
- 通过标准：不责备；说明这次最多考 5 道、其余顺延；第一道考的是标了"有把握却答错"的知识点之一；一次一题。第二轮后看进度文件，其余题的下次复习日期是否已顺延（顺延发生在第一轮或第二轮都算，记录实际看到的情况）。

## T7 只有 10 分钟

- 准备：新文件夹，手工建进度文件：上次上课 2026-11-10，复习队列 1 题今天到期，当前级别 1 进行中。
- 输入：`继续，今天只有10分钟`
- 通过标准：不再问今天有多少时间；安排是复习加最多一个小知识点，明确不开完整新课。

## T8 求职回归

- 输入：
  - 第一轮：`我想转行做数据分析师，带我学`
  - 第二轮：一段自述，加 3 条简短的编造 JD，注明"测试用，直接以这 3 条为准"。
  - 第三轮：`摸底先放一放，我想体验模拟面试`
  - 第四轮：对面试第一题给一个笼统的回答。
- 通过标准：
  - 第一轮一次问清（含岗位方向、有没有 JD），没有考题。
  - 第二轮岗位要求表出现在第一道摸底题之前，只出一道题。
  - 第三轮先说明面试结构，一次一题。
  - 第四轮是追问，没有打分、没有讲解，也没有"提示后再试一次"。
